Scholar App Database Graph

Visual draft of the current Firestore design based on the app code. This shows the main collections and how they are connected right now.

`users` = main account records `applications` = scholarship submissions `withdrawals` = payout requests `grants` = scholarship offerings

Current weakness: `applications` does not store `grant_id` yet. It only stores `grant_title`, so the relationship to `grants` is not fully normalized.
If you want, the next step is a cleaner version for submission with `grant_id`, `role`, and admin/student permissions added.
